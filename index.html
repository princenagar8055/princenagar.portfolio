OnTrack

Habit tracker · Personal project, concept to full build

Most habit trackers either overwhelm you with charts or oversimplify into a checklist. OnTrack sits in between: a daily goal bar that fills as habits get done, a streak history that shows the pattern at a glance, and reminders that actually fire on time — even offline.

Technical highlight

Reminders are built on AlarmManager + BroadcastReceiver + Notification Channels, with WorkManager generating each day's habit history in the background — so streaks stay accurate even if the app never opens that day.

  • Architecture — MVVM with Repository Pattern, keeping presentation, business logic, and data cleanly separated and independently testable
  • Recurrence engine — supports Daily, Weekly, Monthly, Alternate Days, Custom Weekdays, and Custom Dates, each with its own reminder rescheduling logic
  • Reactive data layer — Room + Coroutines + StateFlow for offline-first persistence, so the UI reflects state changes instantly with no manual refresh
  • CRUD — full habit create/edit/delete flow, with reminders automatically rescheduled or cancelled to match
